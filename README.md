# Сравнение монет

Накладывает графики до **5 монет** друг на друга, чтобы их было удобно
сравнивать: режимы «% изменения», «индекс = 100», «цены ± лог-шкала»
и «ratio A/B» (для двух монет).

Особый режим — **сравнение монеты с самой собой за разные периоды**:
выберите одну и ту же монету в первых двух слотах, и у второй линии
появится свой период. Например, BTC за 2026 год поверх BTC за 2025-й,
совмещённые по началу периода; в режиме «Цены» обе линии идут по общей оси.

Один бинарь на Go раздаёт и статику фронтенда, и API-прокси к источникам
данных с кэшированием. Работает без базы данных: состояние экрана — в URL.

> **Источники данных.** Бесплатный CoinGecko отдаёт историю только за
> последние 365 дней — глубже сервер добирает дневными свечами с Binance
> (с 2017 года, без ключа; только пары к USDT).
>
> **Шиткоины с DEX** (пример — токены TON): ищутся по адресу контракта
> и по названию. График строится из свечей главного пула токена
> (GeckoTerminal, без ключа). Ограничения: история DEX-токенов ~6 месяцев,
> а GeckoTerminal агрессивно ограничивает IP при активном долблении —
> первая загрузка может занять до нескольких минут, дальше из кэша.

## Быстрый старт

```bash
# 1. Фронтенд (один раз)
cd web
npm install
npm run build
cd ..

# 2. Сервер
go run ./cmd/server
# открыть http://localhost:8080
```

Переменные окружения:

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `PORT` | `8080` | порт сервера |
| `CG_DEMO_KEY` | — | бесплатный демо-ключ с [coingecko.com](https://www.coingecko.com/en/api) — лимиты заметно выше (30 req/min вместо ~10) |
| `STATIC_DIR` | `web/dist` | где лежит собранный фронтенд |

Пример: `CG_DEMO_KEY=CC... PORT=8080 go run ./cmd/server`

## Режим разработки

Два терминала: Go-сервер (:8080) и Vite dev-сервер (:5173) с горячей
перезагрузкой; `/api` проксируется на Go автоматически.

```bash
go run ./cmd/server          # терминал 1
cd web && npm run dev        # терминал 2 → открыть http://localhost:5173
```

## Структура проекта (что где учить)

```
cmd/server/main.go       — точка входа: конфиг из env, роутинг (Go 1.22+ mux),
                           раздача статики со SPA-fallback, логирование,
                           плавная остановка по Ctrl+C (signal.NotifyContext)
internal/api/            — HTTP-слой, разложен по смыслу:
  server.go                сборка зависимостей, JSON-утилиты, маппинг ошибок
  chart.go                 /api/chart: периоды и выравнивание N серий
                           на общую сетку (union корзин; «от начала периода»
                           для сравнения монеты с собой)
  series.go                маршрутизация источников цен + Binance-сшивка
                           переименований листингов
  search.go                поиск: CoinGecko + адреса контрактов + TonAPI
  markets.go               «живые» данные для чипов
  ton.go                   TON-специфика: пулы DeDust, поиск TonAPI, прогрев
internal/coingecko/      — клиент CoinGecko: таймауты, ретраи при 429/5xx,
                           декодинг JSON в структуры
internal/binance/        — дневные свечи за пределами 365 дней
                           (пагинация по 1000 свечей)
internal/geckoterminal/  — DEX-токены: инфо токена, его пулы, свечи пула
internal/dedust/         — запасной источник адреса TON-пула (когда
                           GeckoTerminal лежит) + парсер тяжёлого списка пулов
internal/tonapi/         — поиск TON-токенов по названию (TonAPI индексирует
                           джеттоны, которых нет в CoinGecko)
internal/tonaddr/        — конвертация TON-адресов raw ↔ EQ (CRC16-XMODEM)
internal/cache/          — дженерик-кэш с TTL: мьютекс + map, «ленивая» чистка
                           и фоновый janitor на goroutine + ticker
web/                     — React + TypeScript + Vite + ECharts:
  src/lib/api.ts           типы ответов сервера и fetch-обёртки
  src/lib/transform.ts    нормализация под режимы сравнения + fillGaps
                           (протягивание цен неликвидных токенов)
  src/components/          PriceChart (обёртка ECharts), CoinSelect (поиск
                           с debounce)
  src/App.tsx              состояние экрана (слоты, периоды) и URL
```

## API

| Метод | Пример | Что делает |
|---|---|---|
| `GET /api/search?q=...` | `/api/search?q=sol` | поиск: CoinGecko + адреса контрактов + TON-токены по имени (кэш 10 мин) |
| `GET /api/coins?ids=...` | `/api/coins?ids=bitcoin,ethereum` | живые данные: лого, цена, 24ч (кэш 1 мин) |
| `GET /api/chart` | `/api/chart?ids=a,b,c&range=90` | выровненные истории цен 2–6 монет |

Периоды для `/api/chart`: `range=1|7|14|30|90|180|365|max|ytd`
или кастомный диапазон `from=2026-08-01&to=2026-09-15`.

Сравнение одной монеты за разные периоды: `ids=bitcoin,bitcoin` плюс
отдельный период второй линии — `range2=...` или `from2/to2`. Линии
совмещаются «от начала периода»: ось X — даты периода первой линии,
вторая сдвигается на них.

Гранулярность выбирает источник: 5-минутная для `range=1`, часовая до
90 дней, дневная дальше — ограничение бесплатного тарифа CoinGecko.

Состояние экрана целиком живёт в URL — любое сравнение можно отправить
ссылкой:

```
/compare/solana/ethereum?range=90&mode=percent&log=1
/compare/bitcoin/ethereum?from=2026-08-01&to=2026-09-15&mode=ratio
/compare/gt%3Aton%2FEQ…/gt%3Aton%2FEQ…/bitcoin?mode=raw&log=1
```
