# Сравнение монет

Накладывает графики двух монет друг на друга, чтобы их было удобно сравнивать:
режимы «% изменения», «индекс = 100», «двойная ось ± лог-шкала» и «ratio A/B».

Особый режим — **сравнение монеты с самой собой за разные периоды**:
выберите одну и ту же монету в обоих слотах, и у второй линии появится
свой период. Например, BTC за 2026 год поверх BTC за 2025-й, совмещённые
по началу периода; в режиме «Цены» обе линии идут по общей оси.

Один бинарь на Go раздаёт и статику фронтенда, и API-прокси к CoinGecko
с кэшированием. Работает без базы данных: пресеты — в URL и localStorage.

> Источники данных: бесплатный CoinGecko отдаёт историю только за
> последние 365 дней. Периоды глубже года сервер добирает дневными
> свечами с Binance (с 2017 года, без ключа; только пары к USDT).
>
> **Шиткоины с DEX**: вставь в поиск адрес контракта — токен найдётся
> через GeckoTerminal, график строится из свечей его главного пула
> (без ключа). История DEX-токенов ограничена ~6 месяцами (лимит
> бесплатного GeckoTerminal). Осторожно с частыми запросами: GT
> агрессивно ограничивает IP при активном долблении.

## Быстрый старт

```bash
# 1. Фронтенд (один раз)
cd web
npm install
npm run build
cd ..

# 2. Сервер
go run ./cmd/server
# открыть http://localhost:8080
```

Переменные окружения:

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `PORT` | `8080` | порт сервера |
| `CG_DEMO_KEY` | — | бесплатный демо-ключ с [coingecko.com](https://www.coingecko.com/en/api) — лимиты заметно выше (30 req/min вместо ~10) |
| `STATIC_DIR` | `web/dist` | где лежит собранный фронтенд |

Пример: `CG_DEMO_KEY=CC... PORT=8080 go run ./cmd/server`

## Режим разработки

Два терминала: Go-сервер (:8080) и Vite dev-сервер (:5173) с горячей
перезагрузкой; `/api` проксируется на Go автоматически.

```bash
go run ./cmd/server          # терминал 1
cd web && npm run dev        # терминал 2 → открыть http://localhost:5173
```

## Структура проекта (что где учить)

```
cmd/server/main.go       — точка входа: конфиг из env, роутинг (Go 1.22+ mux),
                           раздача статики со SPA-fallback, логирование,
                           плавная остановка по Ctrl+C (signal.NotifyContext)
internal/coingecko/      — клиент внешнего API: http.NewRequestWithContext,
                           таймауты, ретраи при 429/5xx и сетевых сбоях,
                           декодинг JSON в структуры
internal/binance/        — второй источник: дневные свечи за пределами
                           365 дней, которые больше не отдаёт бесплатный
                           CoinGecko (пагинация по 1000 свечей)
internal/geckoterminal/  — третий источник: DEX-токены без страницы в
                           CoinGecko. Поиск по адресу контракта, график
                           из свечей главного пула токена (public, без ключа)
internal/api/            — хендлеры /api/search, /api/coins, /api/chart:
                           валидация параметров, выравнивание двух временных
                           рядов на общую сетку (горутины + WaitGroup —
                           обе монеты грузятся параллельно); для одной
                           монеты за разные периоды — выравнивание
                           «от начала периода» (alignRelative)
internal/cache/          — дженерик-кэш с TTL: мьютекс + map, «ленивая» чистка
                           и фоновый janitor на goroutine + ticker
web/                     — React + TypeScript + Vite + ECharts:
  src/lib/api.ts           типы ответов сервера и fetch-обёртки
  src/lib/transform.ts    нормализация данных под каждый режим сравнения
  src/components/          PriceChart (обёртка ECharts), CoinSelect (поиск с debounce)
  src/App.tsx              состояние экрана и синхронизация с URL
```

## API

| Метод | Пример | Что делает |
|---|---|---|
| `GET /api/search?q=...` | `/api/search?q=sol` | поиск монет (кэш 10 мин) |
| `GET /api/coins?ids=...` | `/api/coins?ids=bitcoin,ethereum` | живые данные: лого, цена, 24ч (кэш 1 мин) |
| `GET /api/chart` | `/api/chart?ids=solana,ethereum&range=90` | выровненные истории цен обеих монет |

Периоды для `/api/chart`: `range=1|7|14|30|90|180|365|max|ytd`
или кастомный диапазон `from=2026-08-01&to=2026-09-15`.

Сравнение одной монеты за разные периоды: `ids=bitcoin,bitcoin` плюс
отдельный период второй серии — `range2=...` или `from2/to2`. Серии
совмещаются «от начала периода»: ось X — даты периода A, кривая B
сдвигается на них.

Гранулярность выбирает CoinGecko: 5-минутная для `days=1`, часовая до 90 дней,
дневная дальше — это ограничение бесплатного тарифа.

Состояние экрана целиком живёт в URL — любое сравнение можно отправить ссылкой:

```
/compare/solana/ethereum?range=90&mode=percent&log=1
/compare/bitcoin/ethereum?from=2026-08-01&to=2026-09-15&mode=ratio
```
